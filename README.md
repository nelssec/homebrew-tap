# Homebrew Tap

This repository contains Homebrew formulae for nelssec tools.

## Installation

```bash
brew tap nelssec/tap
brew install qualys-k8s
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| qualys-k8s | Agentless Kubernetes security scanner |

## Updating

Formulae are automatically updated when new releases are published.
